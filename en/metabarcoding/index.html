Proposed workflow

Four analysis steps.

The interface will guide users from input files through quality control and comparison to the final taxonomic profile.

01
Data input

Upload sequencing files and essential sample information.

02
Quality and filtering

Check reads, remove unsuitable records and prepare data for comparison.

03
Taxonomic assignment

Compare sequences with reference data and identify the taxa represented.

04
Profile and report

Visualise sample composition, summarise results and export them for further analysis.
